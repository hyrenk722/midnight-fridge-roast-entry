Entry for the make.fun competition "Midnight Fridge Roast": one roast of a
smart fridge that refuses to open after midnight, a single line under 200
characters. `main.py` writes that roast to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), validating the gate first: UTF-8 text,
1–200 characters, not only whitespace, exactly one line — then reading the
file back to verify the written bytes match.

> Midnight, hungry, and my fridge just stands there locked — the only thing in this house with boundaries.

Why this roast: the setup is the exact scene the judge brief asks for —
midnight, hungry, standing at a locked fridge — and the turn makes the
fridge's petty rule the joke: the one thing in the house with boundaries is
the appliance, not the person. One line, no wasted setup, reads cleanly
aloud in one breath, and the last word, "boundaries", lands the laugh
instead of explaining it.

## Run it

```sh
python3 main.py
```
